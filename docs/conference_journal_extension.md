# Conference-to-Journal Extension Record

The earlier conference paper proposed a high-level architecture comprising
multimodal sensing, a Verified Alert Score, conditional evidence retention,
IPFS storage, and Hyperledger Fabric anchoring.

The journal extension must add:
1. Formal event-probability and preservation-priority definitions.
2. Reproducible public-dataset experiments.
3. Evidence-recall versus retention analysis.
4. Context-policy ablations.
5. Measured IPFS/Fabric latency and integrity tests.
6. Failure analysis.
