# Context Annotation Guidelines

This document will define every manually created context annotation.

No policy or context label may be created without:
1. A written definition.
2. An allowed value list.
3. An annotation source.
4. A rationale.
5. A policy version.
6. Agreement measurement when two annotators are used.

Do not label generic videos as 'bank', 'school', or 'restricted zone' unless
that fact is genuinely documented by the dataset or custom data collection.
