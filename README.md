# Context-Conditioned Selective Evidence Retention

This repository contains the implementation and experiments for a study of
multimodal surveillance-event scoring, selective temporal clip preservation,
and cryptographically verifiable evidence registration.

## Core question

Can calibrated multimodal event evidence and operational-policy context reduce
retained surveillance footage while preserving relevant event evidence?

## Experiment conditions

- C0: Continuous retention
- C1: Video-only selective retention
- C2: Audio-video selective retention
- C3: Audio-video with scene context
- C4: Context-conditioned preservation policy
- C5: Rule-only context policy
- C6: Random duration-matched retention
- C7: Periodic retention
